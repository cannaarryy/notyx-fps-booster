# NOTYX FPS BOOSTER

Menú optimizador de FPS para FiveM. Cambia cielo, iluminación y efectos
visuales sin tocar mapa, tráfico ni objetos. Standalone y ligero.

FPS optimizer menu for FiveM. Changes sky, lighting and visual effects
without touching map, traffic or objects. Standalone, lightweight.

## Presets · Ajustes

| Preset | Uso · Use |
|--------|-----------|
| ULTRA BOOST | Máxima limpieza · Max cleanup |
| RAPID BOOST | Equilibrio · Balanced |
| LOW | PCs modestos · Low-end PCs |
| ORIGINAL | Restaurar visuals · Restore visuals |

Filtros especiales · Special filters: Noche Eterna · Niebla Densa ·
Blanco y Negro · Calor · Viñeta. Botón RESET instantáneo + FPS en
tiempo real · Instant RESET button + live FPS.

## Instalación · Install

1. Descarga `Notyx-Fps.zip` de este repositorio.
2. Extrae la carpeta en `resources/`.
3. Añade `ensure notyx-fps` (nombre de la carpeta extraída) a tu `server.cfg`.
4. Reinicia el servidor.

## Compatibilidad · Compatibility

ESX · QBCore · Qbox (standalone, sin dependencias).
